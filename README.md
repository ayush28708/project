# ⚡ SPORETS LIVE - Universal Sports Hub & Streaming Platform

> **Watch Live Sports • Interactive Full Scorecards • Ball-by-Ball Live Commentary • Pirate Stream Parody Mode**

---

## 🌟 Features

### 1. 📺 Live Sports Video Broadcast & Pitch Radar
- Custom video player with Play/Pause, Mute/Volume slider, Picture-in-Picture, Fullscreen, and Stream Server switcher.
- **2D Virtual Tactical Pitch Radar**: Real-time canvas animated pitch tracking fielders, ball trajectories, and match action for Cricket, Football, and Basketball.
- **Audio Radio Mode**: Stream stadium ambient sounds and radio commentary.
- **Floating Live Reactions**: Interactive emojis (🔥, 🏏, ⚽, 👏, 🏆, 😱) that float up with sound effects.

### 2. 📊 Comprehensive Multi-Sport Scorecards
- **🏏 Cricket**: Full ESPNcricinfo/Cricbuzz-style detailed scorecard (Batting runs, balls, 4s, 6s, strike rate, dismissal; Bowling overs, maidens, runs, wickets, economy, dots; Fall of Wickets; Live on-crease widget; Innings 1 vs 2 switcher).
- **⚽ Football (Soccer)**: Goals timeline with scorer & minute, tactical formations (4-3-1-2 vs 4-1-4-1) with live player ratings, and comparative match statistics (Possession %, xG, Shots on target, Corners, Fouls).
- **🏀 Basketball (NBA)**: Quarter-by-quarter scoring table (Q1-Q4) and box score stats (PTS, REB, AST, FG, 3PT, MIN).
- **🎾 Tennis**: Set-by-set breakdown, game points tracker, and serving/rally statistics (Aces, Double faults, 1st serve %, Break points won).
- **🏎️ Formula 1**: Real-time Grand Prix leaderboard with intervals, tire compounds, pit stops, and purple fastest-lap badges.

### 3. 🎙️ Ball-by-Ball Live Commentary Engine
- Real-time commentary updates with color-coded event badges (*SIX, FOUR, WICKET, GOAL, CARD*).
- **Audio Voice Commentary (Speech Synthesis)**: Click to listen to commentators read the live events out loud.
- **Live Simulator**: Automatically generates new realistic balls/minutes and plays synthesized crowd roars and bat crack audio.

### 4. 💬 Fan Community & Match Polls
- Real-time community live chat and user comment submission.
- Interactive live match prediction polls with dynamic percentage tracking.

### 5. 🏴‍☠️ Pirate Stream & Cursed Keyboard Mode (Parody Chaos)
- Authentic annoying free sports stream parodies:
  - Hydra Popups (closing an ad triggers VAR penalties and spawns 2 new ads).
  - Cursed Keyboard (Space flips screen 180°, Enter triggers jumpscare eyes 👁️👁️, Backspace spawns spiders 🕷️, Escape triggers red cards).
  - AFK Inactivity Penalty, Exit-Intent Trap, and Bouncing DVD Ads.
  - Floating Pinned Match Dock so the match remains 100% watchable throughout!
  - "I'M CRYING 😭" Panic Button to clear all ads for 25 seconds.
